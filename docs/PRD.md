# 韩国星际争霸团战战报自动生成系统

本项目按根目录需求文档实现自动工作流：

1. 抓取 ELOBoard 团战列表和详情页。
2. 解析比赛日期、队伍、总比分、每局地图、选手、种族和胜负。
3. 使用 `translate_rules.md` 转换选手名和地图名；未命中时保留原文。
4. 自动生成公众号风格标题、导语、对局回顾、MVP 和总结。
5. 使用 Pillow 生成头图、单局对阵卡、MVP 卡。
6. 生成公众号兼容 HTML。
7. 可选上传微信公众号草稿、发送 PushPlus 通知。
8. 使用本地 SQLite 去重，避免重复生成同一 `match_id`。

默认不发布到外部平台。配置 `.env` 并设置 `DRY_RUN=0` 后，`--publish` 才会创建公众号草稿。
